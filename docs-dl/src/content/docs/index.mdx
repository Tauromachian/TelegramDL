## ¿Qué es TelegramDL?

TelegramDL es un gestor de descargas especializado, desarrollado en **Go**, **Wails v2** y **Vue 3**. Combina un backend ultrarrápido y concurrente con una interfaz moderna y reactiva.

<CardGrid stagger>
	<Card title="Descargas Multihilo" icon="rocket">
		Divide cada archivo en bloques de 512 KB con hasta 8 workers en paralelo por descarga.
	</Card>
	<Card title="Vigilante en Vivo" icon="magnifier">
		Monitorea canales y grupos en tiempo real con filtros por tipo de multimedia y autodescarga.
	</Card>
	<Card title="Acceso Remoto Protegido" icon="laptop">
		Controla la aplicación desde cualquier dispositivo mediante autenticación segura por Token Bearer.
	</Card>
	<Card title="Reanudación Automática" icon="refresh">
		Reanuda descargas incompletas desde los fragmentos ya guardados sin reiniciar desde cero.
	</Card>
</CardGrid>

---

## Características Destacadas

- **Soporte para rangos de mensajes**: Descarga múltiples mensajes continuos utilizando URLs de rango.
- **Canales y grupos con temas (topics)**: Capacidad para descargar temas específicos o escuchar grupos completos.
- **Modo Servidor Headless**: Puede ejecutarse sin interfaz gráfica mediante el parámetro `--server`.
- **Base de datos SQLite local**: Gestión eficiente sin dependencias externas (CGO-free).
